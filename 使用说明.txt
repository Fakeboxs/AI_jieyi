截译 · JieYi  0.1.0
==================

截图即得译文：框选屏幕任意区域 → AI 视觉模型翻译 → 公式/表格原样排版 → 一键复制。

一、安装
--------
1. 双击 JieYi_0.1.0_x64-setup.exe。
2. 安装位置：%LOCALAPPDATA%\JieYi（当前用户，无需管理员权限）。
3. 若提示缺少 WebView2，安装程序会自动下载并安装（需要联网）。
4. 若 Windows 弹出「Windows 已保护你的电脑」（SmartScreen），这是未签名安装包的常规提示：
   点「更多信息」→「仍要运行」，或在文件属性里勾选「解除锁定」后再运行。

二、首次使用
------------
1. 启动后进入「设置 → 模型服务」：
   - 服务商：OpenAI 兼容 / Anthropic / Gemini / 自定义
   - API 基础地址：例如 https://api.siliconflow.cn/v1
   - API Key：你自己的密钥（只保存在本机 %APPDATA%\app.jieyi.desktop\config.json）
   - 模型名称：需支持图片输入的视觉模型，例如 Qwen/Qwen2.5-VL-72B-Instruct
   - 点「测试连接」确认可用，再点「保存设置」
2. 在任意界面按 Ctrl + Alt + S（或托盘图标左键）框选要翻译的区域。
3. 结果自动出现，右下角「复制译文」或 Ctrl+Shift+C 复制。
4. 每次翻译都会进入「归档」，可搜索、按标签筛选、展开复制或删除。

三、输出方式
------------
设置 → 翻译偏好 → 输出方式：
- 流式返回（SSE）：首字到达即显示，边生成边排版（默认，推荐）
- 一次性直出：等整段返回再显示（适合不支持 SSE 的网关）

四、常见问题
------------
Q: 按 Ctrl+Alt+S 没反应？
A: 该热键可能被其它软件占用。可改用托盘图标左键截图；关闭占用热键的程序后重启本应用。

Q: 提示「还没有填写 API Key」？
A: 到设置里填写 Key 并保存。

Q: 公式显示成 $...$ 原文？
A: 模型没有按 LaTeX 输出。检查提示词是否要求「公式使用 LaTeX」；设置里已内置该要求。

Q: 想换掉本机数据/彻底清除？
A: 卸载只删程序；数据在 %APPDATA%\app.jieyi.desktop（config.json、jieyi.db、images\），可手动删除。

五、卸载
--------
Windows 设置 → 应用 → 截译 → 卸载（或 %LOCALAPPDATA%\JieYi\uninstall.exe）。

六、隐私
--------
- 无任何遥测/统计。
- 截图只发送给你自己配置的模型服务商；不经过任何第三方中转。
- API Key 以明文保存在本机配置文件，请勿共享该文件。
