截译 · JieYi  0.4.1
==================

截图即得译文：框选屏幕任意区域 → AI 视觉模型翻译 → 公式/表格原样排版 → 一键复制或导出。

一、安装
--------
1. 双击 JieYi_0.4.1_x64-setup.exe。
2. 安装位置：%LOCALAPPDATA%\截译（当前用户，无需管理员权限）。
3. 若提示缺少 WebView2，安装程序会自动下载并安装（需要联网）。
4. 若 Windows 弹出「Windows 已保护你的电脑」（SmartScreen），这是未签名安装包的常规提示：
   点「更多信息」→「仍要运行」，或在文件属性里勾选「解除锁定」后再运行。

二、首次使用
------------
1. 启动后进入「设置 → 模型服务」：
   - 服务商：OpenAI 兼容 / Anthropic / Gemini / 自定义端点 / 高级模板
   - API 基础地址：例如 https://api.siliconflow.cn/v1
   - API Key：你自己的密钥（只保存在本机 %APPDATA%\app.jieyi.desktop\config.json）
   - 模型名称：需支持图片输入的视觉模型，例如 Qwen/Qwen2.5-VL-72B-Instruct
   - 点「测试连接」确认可用，再点「保存设置」
2. 在任意界面按 Ctrl + Alt + S（或托盘图标左键）框选要翻译的区域。
3. 结果自动出现，点卡片右上「复制译文」或按 Ctrl+Shift+C 复制。
4. 每次翻译都会进入「归档」，可搜索、按标签筛选、展开复制/导出/删除。

三、结果窗口
------------
- 默认：译文出现在“选区旁的窄边置顶小窗”里，不打断你正在做的事。
  小窗可拖动（拖顶部条）、可缩放；点「复制译文」或 Ctrl+C 复制，点「在主窗口打开」跳到主窗口查看；Esc 或右上角 × 关闭。
- 想改回把结果放进主窗口：设置 → 截图 → 翻译结果显示在 → 主窗口。

四、框选与快捷键
----------------
- 拖动一次 = 框一块；可以连续框多块，点浮层底部「翻译 N 块」或按 Enter，把这几块一起发给模型（一次请求、一份译文）。
- 浮层底部还有「撤销」「取消」按钮；键盘 Backspace / Esc 同样有效。
- 焦点没落在浮层上时按钮照样能点，不会出现"按了没反应"。
- 「记住上次框选区域」开启时，再次截图会用虚线预选上次的框：
  直接 Enter 复用；随手拖新框则会顶掉预选。
- Ctrl + Alt + D：跳过选区，直接按上次位置重新截图翻译（适合连续翻同一块区域，例如论文同一栏）。
- 托盘右键菜单同样提供「截图翻译 / 重复上次区域 / 显示主窗口 / 退出」。
- 快捷键可以改（见第九节）：两个全局热键都能换成你顺手的组合。

五、文本翻译（不用截图）
------------------------
主界面第二个标签「文本」（Ctrl + 2）：
- 把外文粘进输入框，按 Ctrl + Enter 或点「翻译」；
- 「粘贴」按钮直接读剪贴板，「清空」一键清掉输入；
- 译文和截图翻译走同一条管线（流式、公式、表格、一键复制都一样），
  并且自动进归档 —— 只是这条记录没有截图，所以没有「重新翻译」按钮；
- 适合翻 PDF 里复制的一段、邮件正文、网页段落。单次上限约 2 万字符。

六、离线翻译（不用 API、断网也能用）
------------------------------------
设置 → 模型服务 → 服务商选「本地离线」，然后：

1. 选引擎
   - 视觉模型（推荐）：Qwen2.5-VL-3B，识图+翻译一步完成，公式与排版保留最好，资源包约 2.8 GB
   - 轻量 OCR：Windows 自带 OCR 认字 + Qwen2.5-1.5B 翻译，资源包约 1.1 GB，CPU 也能跑，但只有纯文本
2. 直接用「本地服务」里那个按钮：
   - 还没有模型/运行时 → 按钮显示「启动（自动下载）」，点它会依次：下载 → 解压部署 → 启动
   - 已经有了 → 按钮显示「启动本地服务」，点了就加载（约 10-20 秒）
   - 启动后显示「运行中 · 端口 xxxxx · 视觉模型」，按钮变成「停止本地服务」
   - 关闭窗口（收进托盘）不会停服务；真正退出程序或强杀进程时，本地服务会一起退出，
     不会在后台占着内存/显存

   也可以逐个点「资源包」里的「下载」，有进度条；下完就可以拔网线了
   - 文件落在 %APPDATA%\app.jieyi.desktop\models，换机器时整目录拷过去即可
   - 走的是 hf-mirror / gh-proxy 镜像，断了下一次会续传，坏包会自动重下

   也可以自己手动下（应用不上传这些大文件，链接与内置清单一致）：
   - 运行时：github.com/ggml-org/llama.cpp/releases/download/b12500/llama-b12500-bin-win-vulkan-x64.zip
     （国内打不开就在前面加 https://gh-proxy.com/），解压到 models\runtime\，里面要有 llama-server.exe
   - 视觉包：
     huggingface.co/ggml-org/Qwen2.5-VL-3B-Instruct-GGUF/resolve/main/Qwen2.5-VL-3B-Instruct-Q4_K_M.gguf
     huggingface.co/ggml-org/Qwen2.5-VL-3B-Instruct-GGUF/resolve/main/mmproj-Qwen2.5-VL-3B-Instruct-Q8_0.gguf
     两个都放进 models\vlm\（域名换成 hf-mirror.com 更快）
   - 轻量包：
     huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF/resolve/main/qwen2.5-1.5b-instruct-q4_k_m.gguf
     放进 models\ocr\
3. 点「测试连接」：会真的把本地模型加载起来，显示「本地引擎已就绪（http://127.0.0.1:端口，用时 x.xs）」
4. 之后 Ctrl+Alt+S 截图翻译，流程和云端完全一样；首次翻译会自动加载模型（几秒到十几秒）

关于资源和速度：
- 3B 视觉模型约占 2.4 GB 显存；显存不够时启动会失败，错误里会带上 llama-server.log 的原因
- 实测（RTX 5060 8GB）：首字 1.7 秒、整段 2.1 秒；纯 CPU 慢 3-5 倍
- 「停止本地服务」按钮可以把模型从显存里退出来（下次翻译会自动重新加载）；
  退出应用时服务也会自动退出，强杀进程也一样（用 Windows 作业对象把所有子进程带走）
- 本地 3B 模型对长段落和密集公式不如云端稳，术语偶尔不准，建议当成断网兜底

七、输出方式与停止
------------------
设置 → 翻译偏好 → 输出方式：
- 流式返回（SSE）：首字到达即显示，边生成边排版（默认，推荐）
- 一次性直出：等整段返回再显示（适合不支持 SSE 的网关）

流式模式下，生成过程中可随时点卡片右上「停止」：已生成的部分会保留，并照常存入归档。

八、多显示器
------------
设置 → 截图 → 捕获屏幕：「跟随鼠标所在屏幕」（默认）或固定某一块屏幕。
分辨率按各自的缩放比（125% / 150% 等）换算，切割位置不会错位。

九、标签与导出
--------------
- 结果卡片底部点「+ 标签」→ 输入名称回车即可添加；点标签上的 × 移除。
- 卡片右上「导出」按钮把当前译文另存为 .md（自动带上标签与来源信息）。
- 归档页顶部有搜索框与标签过滤。

十、高级 API 模板
-----------------
服务商选「高级模板」，自己拼请求：
- Endpoint：可以带占位符，例如 https://host/v1/models/{{model}}:generate
- Headers：逐行添加，值里同样可以用占位符（如 Bearer {{api_key}}）
- 请求体：JSON 模板，用 {{model_json}} {{prompt_json}} {{image_parts}} {{stream}} 等占位符
- 响应字段：JSON Pointer（如 /choices/0/message/content），留空则自动识别常见结构
点「填入示例」可得到一份 OpenAI 形状的模板，再按你的服务改。

十一、归档清理
------------
- 归档页每条记录左侧有勾选框；顶部操作条提供「全选 / 全选筛选结果」「删除选中」「清空全部」。
- 删除会连同该条记录的截图文件一起清理，操作前有确认弹窗，无法撤销。

十二、改快捷键
--------------
设置 → 快捷键与数据：
- 「截图翻译」「重复上次区域」两个输入框，点一下变成「按下组合键…」，
  直接按你想要的组合（至少带一个 Ctrl / Alt / Shift / Super），Esc 取消；
- 保存时会真的去系统里注册一次：
  · 组合被别的软件占用 → 提示「注册失败：可能已被其它程序占用」，原来的绑定继续有效；
  · 两个功能填成同一个 → 输入框下方出现红字，保存按钮变灰，改掉才能存；
- 托盘菜单里的热键提示会跟着改，不用重启。

十三、常见问题
------------
Q: 按 Ctrl+Alt+S 没反应？
A: 十有八九是这个组合被别的软件占了（常见：QQ / 微信 / TIM 的截图键、搜狗与微软拼音的
   快捷键、ShareX、Snipaste、网易UU、部分游戏加速器，以及显卡驱动的录屏）。
   新版本会在主窗口顶部直接弹一条红条说明「注册失败：已被其它程序占用」，
   点红条上的「重新注册」即可重试；也可以到设置 → 快捷键与数据换一个组合
   （那里还会显示两个绿色的「已注册」徽标，一眼看出是不是真的注册上了）。
   兜底办法：托盘图标左键 = 立刻截图。

Q: 提示「还没有填写 API Key」？
A: 到设置里填写 Key 并保存。

Q: 公式显示成 $...$ 原文？
A: 模型没有按 LaTeX 输出。检查提示词是否要求「公式使用 LaTeX」；设置里已内置该要求。

Q: 一次框多块，模型把它们当成一段怎么办？
A: 提示词里说明「多张图片按顺序拼接」，或改成逐块翻译（每次只框一块）。

Q: 想换掉本机数据/彻底清除？
A: 卸载只删程序；数据在 %APPDATA%\app.jieyi.desktop（config.json、jieyi.db、images\、last_region.json），可手动删除。

十四、关闭窗口与退出
--------------------
- 点窗口右上角 × 只是**收进托盘**，程序继续在后台待命（截图热键仍然有效）。
- 要真正结束程序：右键托盘图标 → 退出。
- 托盘图标左键 = 立刻截图；双击桌面图标不会重复启动，会把已有窗口叫到前台。

十五、卸载
--------
Windows 设置 → 应用 → 截译 → 卸载（或 %LOCALAPPDATA%\截译\uninstall.exe）。

十六、隐私
----------
- 无任何遥测/统计。
- 截图只发送给你自己配置的模型服务商；不经过任何第三方中转。
- API Key 以明文保存在本机配置文件，请勿共享该文件。
