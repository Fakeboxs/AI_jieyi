截译 · JieYi  0.4.1
==================

截图即得译文：框选屏幕任意区域 → AI 视觉模型翻译 → 公式/表格原样排版 → 一键复制或导出。

一、安装
--------
1. 双击 JieYi_0.4.1_x64-setup.exe。
2. 安装位置：%LOCALAPPDATA%\截译（当前用户，无需管理员权限）。
3. 若提示缺少 WebView2，安装程序会自动下载并安装（需要联网）。
4. 若 Windows 弹出「Windows 已保护你的电脑」（SmartScreen），这是未签名安装包的常规提示：
   点「更多信息」→「仍要运行」，或在文件属性里勾选「解除锁定」后再运行。

二、首次使用
------------
1. 启动后进入「设置 → 模型服务」：
   - 服务商：OpenAI 兼容 / Anthropic / Gemini / 自定义端点 / 高级模板
   - API 基础地址：例如 https://api.siliconflow.cn/v1
   - API Key：你自己的密钥（只保存在本机 %APPDATA%\app.jieyi.desktop\config.json）
   - 模型名称：需支持图片输入的视觉模型，例如 Qwen/Qwen2.5-VL-72B-Instruct
   - 点「测试连接」确认可用，再点「保存设置」
2. 在任意界面按 Ctrl + Alt + S（或托盘图标左键）框选要翻译的区域。
3. 结果自动出现，点卡片右上「复制译文」或按 Ctrl+Shift+C 复制。
4. 每次翻译都会进入「归档」，可搜索、按标签筛选、展开复制/导出/删除。

三、结果窗口
------------
- 默认：译文出现在“选区旁的窄边置顶小窗”里，不打断你正在做的事。
  小窗可拖动（拖顶部条）、可缩放；点「复制译文」或 Ctrl+C 复制，点「在主窗口打开」跳到主窗口查看；Esc 或右上角 × 关闭。
- 想改回把结果放进主窗口：设置 → 截图 → 翻译结果显示在 → 主窗口。

四、框选与快捷键
----------------
- 拖动一次 = 框一块；可以连续框多块，点浮层底部「翻译 N 块」或按 Enter，把这几块一起发给模型（一次请求、一份译文）。
- 浮层底部还有「撤销」「取消」按钮；键盘 Backspace / Esc 同样有效。
- 焦点没落在浮层上时按钮照样能点，不会出现"按了没反应"。
- 「记住上次框选区域」开启时，再次截图会用虚线预选上次的框：
  直接 Enter 复用；随手拖新框则会顶掉预选。
- Ctrl + Alt + D：跳过选区，直接按上次位置重新截图翻译（适合连续翻同一块区域，例如论文同一栏）。
- 托盘右键菜单同样提供「截图翻译 / 重复上次区域 / 显示主窗口 / 退出」。

五、输出方式与停止
------------------
设置 → 翻译偏好 → 输出方式：
- 流式返回（SSE）：首字到达即显示，边生成边排版（默认，推荐）
- 一次性直出：等整段返回再显示（适合不支持 SSE 的网关）

流式模式下，生成过程中可随时点卡片右上「停止」：已生成的部分会保留，并照常存入归档。

六、多显示器
------------
设置 → 截图 → 捕获屏幕：「跟随鼠标所在屏幕」（默认）或固定某一块屏幕。
分辨率按各自的缩放比（125% / 150% 等）换算，切割位置不会错位。

七、标签与导出
--------------
- 结果卡片底部点「+ 标签」→ 输入名称回车即可添加；点标签上的 × 移除。
- 卡片右上「导出」按钮把当前译文另存为 .md（自动带上标签与来源信息）。
- 归档页顶部有搜索框与标签过滤。

八、高级 API 模板
-----------------
服务商选「高级模板」，自己拼请求：
- Endpoint：可以带占位符，例如 https://host/v1/models/{{model}}:generate
- Headers：逐行添加，值里同样可以用占位符（如 Bearer {{api_key}}）
- 请求体：JSON 模板，用 {{model_json}} {{prompt_json}} {{image_parts}} {{stream}} 等占位符
- 响应字段：JSON Pointer（如 /choices/0/message/content），留空则自动识别常见结构
点「填入示例」可得到一份 OpenAI 形状的模板，再按你的服务改。

九、归档清理
------------
- 归档页每条记录左侧有勾选框；顶部操作条提供「全选 / 全选筛选结果」「删除选中」「清空全部」。
- 删除会连同该条记录的截图文件一起清理，操作前有确认弹窗，无法撤销。

十、常见问题
------------
Q: 按 Ctrl+Alt+S 没反应？
A: 该热键可能被其它软件占用。可改用托盘图标左键截图；关闭占用热键的程序后重启本应用。

Q: 提示「还没有填写 API Key」？
A: 到设置里填写 Key 并保存。

Q: 公式显示成 $...$ 原文？
A: 模型没有按 LaTeX 输出。检查提示词是否要求「公式使用 LaTeX」；设置里已内置该要求。

Q: 一次框多块，模型把它们当成一段怎么办？
A: 提示词里说明「多张图片按顺序拼接」，或改成逐块翻译（每次只框一块）。

Q: 想换掉本机数据/彻底清除？
A: 卸载只删程序；数据在 %APPDATA%\app.jieyi.desktop（config.json、jieyi.db、images\、last_region.json），可手动删除。

十一、关闭窗口与退出
--------------------
- 点窗口右上角 × 只是**收进托盘**，程序继续在后台待命（截图热键仍然有效）。
- 要真正结束程序：右键托盘图标 → 退出。
- 托盘图标左键 = 立刻截图；双击桌面图标不会重复启动，会把已有窗口叫到前台。

十二、卸载
--------
Windows 设置 → 应用 → 截译 → 卸载（或 %LOCALAPPDATA%\截译\uninstall.exe）。

十三、隐私
----------
- 无任何遥测/统计。
- 截图只发送给你自己配置的模型服务商；不经过任何第三方中转。
- API Key 以明文保存在本机配置文件，请勿共享该文件。
